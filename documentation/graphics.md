# Gráficos

PIE/LZS/CMP documentados em [FORMATOS](FORMATOS.md).12268 frames extraídos; máscaras de transparência distintas de índice zero. C# lê os mesmos formatos diretamente para texturas RGBA. Ativos não foram redesenhados nem ampliados por IA. Paletas dinâmicas e composição de objetos ainda pendentes.

As prévias PNG e os assets de runtime têm funções diferentes: o protótipo lê as cópias legadas, não uma imagem estática do mapa.
